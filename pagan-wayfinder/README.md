# Pagan Wayfinder

A free, static multi-page website for exploring modern paganism, witchcraft, and earth-centered spirituality.

## How to open in Visual Studio Code

1. Extract this folder (or clone/copy it) to a location on your computer.
2. Open Visual Studio Code.
3. File → Open Folder… and select the `pagan-wayfinder` folder.
4. Install the **Live Server** extension (by Ritwick Dey) if you don’t already have it.
5. Right-click `index.html` → “Open with Live Server”.

You can also simply open `index.html` directly in any modern browser (Chrome, Firefox, Safari, Edge). Relative links will work.

## Features included

- Responsive design (mobile + desktop)
- Shared navigation and footer across all pages
- Fully working Path Quiz with scoring and personalized results
- Clean, modern, nature-inspired visual design
- SEO-friendly titles and meta descriptions
- Accessibility considerations (semantic HTML, keyboard nav, contrast)
